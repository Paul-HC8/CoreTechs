# Core Techs — Portfolio

An interactive, monochrome developer portfolio and environmental advocacy progress hub.

## Features
- Fixed left sidebar with clickable **CT** logo and tab navigation (`Home`, `Projects`, `Activities`, `About Me`)
- Live monochrome **GitHub Contributions Island**
- Light, Dark, and System theme switcher with saved preferences
- Responsive mobile navigation with Escape-key support

## Quick Setup
1. Open `script.js` and replace `"torvalds"` in `GITHUB_USERNAME` with your GitHub username.
2. Open `index.html` in any web browser to preview locally.
